IvyRadar

A full-stack information and social platform bringing together education, investing, and AI-driven insights — built on the MERN stack with a dedicated moderation dashboard for the content behind it.

role

duration

live at
ivyradar.com

The problem

IvyRadar set out to be a single place for content spanning education, investing, and AI-driven insights — three subject areas that normally live on three different sites. That meant the platform needed a flexible content model, a way to keep quality and moderation consistent across very different content types, and a UI that didn't feel bolted together.

What I built

  • Core platform features on the MERN stack, from data model through to the user-facing interface.
  • An admin dashboard purpose-built for content moderation, user management, and day-to-day data oversight — the internal tool the team actually runs the platform through.
  • API endpoints and database schema designed alongside the rest of the team to support a content-heavy, multi-category platform without the data model becoming a bottleneck.

Approach

  • Treated the admin dashboard as a first-class product surface, not an afterthought — moderation and user-management tools that are actually usable day to day directly affect content quality on a platform like this.
  • Worked schema-first on the database design so new content types (education vs. investing vs. AI insights) could be added without repeated migrations.
  • Kept the API layer collaborative with the rest of the team, since a content-heavy platform lives or dies on how well the backend and frontend agree on shape early.

Outcome

A working platform with distinct content verticals under one roof, backed by an admin dashboard that gives the team direct control over moderation and data — the piece that keeps a multi-topic platform manageable as it grows.
